# کلینیک دندانپزشکی آرمان

وب‌سایت چندصفحه‌ای فارسی (RTL) برای یک کلینیک دندانپزشکی، با طراحی مینیمال
روشن و مدرن. ساخته‌شده با Next.js 16، Tailwind CSS 4 و فونت استعداد.

> محتوای سایت نمونه است (نام‌ها، پزشکان، تعرفه‌ها و نظرات) و باید پیش از
> استفاده واقعی با اطلاعات درست جایگزین شود.

## ویژگی‌ها

- صفحه اصلی با هیرو دوستونی، خدمات، معرفی کلینیک، گالری، پزشک، نظرات و سؤالات
- صفحه خدمات با فهرست شماره‌دار، توضیحات، ویژگی‌ها و تعرفه تقریبی
- صفحه درباره پزشک با بیوگرافی، تایم‌لاین و تیم درمان
- گالری «قبل و بعد» با اسلایدر تصویری (ماوس، لمس و کیبورد)
- نوبت‌دهی آنلاین سه‌مرحله‌ای: خدمت، تقویم شمسی و ساعت آزاد، اطلاعات بیمار
- اعتبارسنجی فرم‌ها، کد پیگیری، ذخیره نوبت در مرورگر و امکان لغو
- صفحه تماس با نقشه سبک، اطلاعات تماس و فرم پیام
- ریسپانسیو، فونت محلی فارسی، متادیتا، `sitemap` و `robots`
- Lighthouse: دسترس‌پذیری، SEO و Best Practices برابر ۱۰۰

## اجرا

```bash
npm install
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) بالا می‌آید.

ساخت نسخه تولید:

```bash
npm run build
npm start
```

## ساختار پروژه

```text
src/
  app/                 صفحات و لایه اصلی (App Router)
    page.tsx           صفحه اصلی
    services/          خدمات
    about/             درباره پزشک
    gallery/           نتایج / قبل و بعد
    appointment/       رزرو نوبت
    contact/           تماس با ما
    globals.css        توکن‌های رنگ، فونت و کلاس‌های پایه
  components/          کامپوننت‌های مشترک و تعاملی
  lib/
    site.ts            تمام محتوای متنی و داده‌های سایت
    booking.ts         منطق تقویم، ساعت‌ها و ذخیره‌سازی نوبت
    format.ts          تبدیل اعداد فارسی/انگلیسی
public/images/         عکس‌های سایت (استوک، قابل جایگزینی)
```

## شخصی‌سازی

- **متن‌ها، خدمات، پزشکان، تعرفه‌ها و نظرات:** `src/lib/site.ts`
- **رنگ‌ها و فونت:** بخش `@theme` در `src/app/globals.css`
- **لوگو و فاوآیکون:** `src/app/icon.svg` و هدر در `src/components/Header.tsx`
- **فونت:** `src/app/fonts/Estedad-Variable.woff2` و `next/font/local` در `src/app/layout.tsx`
- **عکس‌ها:** `public/images/` — پیش از انتشار، با عکس‌های واقعی کلینیک و بیماران
  (با رضایت کتبی) جایگزین شوند.

## درباره نوبت‌دهی

نسخه فعلی فقط سمت کلاینت است:

- نوبت‌ها در `localStorage` با کلید `arman-appointments-v1` ذخیره می‌شوند.
- ساعت‌های رزروشده در همان مرورگر غیرفعال نمایش داده می‌شوند.
- برای استفاده واقعی، فرم را به یک API Route و دیتابیس وصل کنید و ارسال پیامک
  تأیید را اضافه کنید.

برای اتصال به بک‌اند، تابع `submit` در
`src/components/AppointmentForm.tsx` را تغییر دهید و منطق
`readAppointments`/`saveAppointments` را با فراخوانی سرور جایگزین کنید.

## تصاویر و اعتبارها

عکس‌های این پروژه از استوک آزاد (Pexels و Unsplash) هستند و فقط برای نمایش
نمونه استفاده شده‌اند. فهرست منبع‌ها در
[`public/images/CREDITS.md`](public/images/CREDITS.md) آمده است.
