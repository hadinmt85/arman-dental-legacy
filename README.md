# کلینیک دندانپزشکی آرمان

وب‌سایت چندصفحه‌ای فارسی (RTL) برای یک کلینیک دندانپزشکی، ساخته‌شده با
Next.js 16 و Tailwind CSS 4. طراحی رسمی و شرکتی با پالت سرمه‌ای، کرم و طلایی.

> محتوای سایت نمونه است (نام کلینیک، پزشکان، تعرفه‌ها و نظرات) و باید پیش از
> استفاده واقعی با اطلاعات درست جایگزین شود.

## ویژگی‌ها

- صفحه اصلی با هیرو تعاملی، خدمات، مسیر درمان، معرفی پزشک، گالری، نظرات و سؤالات متداول
- صفحه خدمات با توضیحات، ویژگی‌ها و تعرفه تقریبی هر درمان
- صفحه درباره پزشک با بیوگرافی، تایم‌لاین حرفه‌ای و تیم درمان
- گالری «قبل و بعد» با اسلایدر مقایسه‌ای (ماوس، لمس و کیبورد)
- نوبت‌دهی آنلاین سه‌مرحله‌ای: انتخاب خدمت، تقویم شمسی و ساعت‌های آزاد، اطلاعات بیمار
- اعتبارسنجی فرم‌ها، کد پیگیری، ذخیره نوبت‌ها در مرورگر و امکان لغو نوبت
- صفحه تماس با نقشه شبیه‌سازی‌شده، اطلاعات تماس و فرم پیام
- ریسپانسیو، فونت فارسی محلی (Vazirmatn)، متادیتا، `sitemap` و `robots`
- دسترس‌پذیری و SEO با امتیاز کامل در Lighthouse

## اجرا

```bash
npm install
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) بالا می‌آید.

ساخت نسخه تولید:

```bash
npm run build
npm start
```

## ساختار پروژه

```text
src/
  app/                 صفحات و لایه اصلی (App Router)
    page.tsx           صفحه اصلی
    services/          خدمات
    about/             درباره پزشک
    gallery/           گالری قبل و بعد
    appointment/       رزرو نوبت
    contact/           تماس با ما
    globals.css        توکن‌های رنگ، فونت و کلاس‌های پایه
  components/          کامپوننت‌های مشترک و تعاملی
  lib/
    site.ts            تمام محتوای متنی و داده‌های سایت
    booking.ts         منطق تقویم، ساعت‌ها و ذخیره‌سازی نوبت
    format.ts          تبدیل اعداد فارسی/انگلیسی
```

## شخصی‌سازی

- **متن‌ها، خدمات، پزشکان، تعرفه‌ها و نظرات:** `src/lib/site.ts`
- **رنگ‌ها و فونت:** بخش `@theme` در `src/app/globals.css`
- **لوگو و فاوآیکون:** `src/components/Header.tsx` و `src/app/icon.svg`
- **فونت:** `src/app/fonts/Vazirmatn-Variable.woff2` و تنظیمات `next/font/local` در `src/app/layout.tsx`

## درباره نوبت‌دهی

نسخه فعلی فقط سمت کلاینت است:

- نوبت‌ها در `localStorage` با کلید `arman-appointments-v1` ذخیره می‌شوند.
- ساعت‌های رزروشده در همان مرورگر غیرفعال نمایش داده می‌شوند.
- برای استفاده واقعی، فرم را به یک API Route و دیتابیس وصل کنید و ارسال پیامک
  تأیید را اضافه کنید.

برای اتصال به بک‌اند، تابع `submit` در
`src/components/AppointmentForm.tsx` را تغییر دهید و منطق
`readAppointments`/`saveAppointments` را با فراخوانی سرور جایگزین کنید.

## تصاویر

تصاویر «قبل و بعد» و پرتره پزشک، تصویرسازی SVG و شبیه‌سازی‌شده هستند
(`src/components/SmileArt.tsx`). برای جایگزینی با عکس واقعی، کامپوننت
`BeforeAfter` را به تصاویر واقعی بیمار (با رضایت کتبی) متصل کنید و بخش
شفافیت گالری را به‌روز نگه دارید.
